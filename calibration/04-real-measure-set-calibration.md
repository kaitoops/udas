## 三、判别

1. **A3（混合 8 视角）通过，复现防御意图。**
   300° 贴近 288°，与原始 FNV 分析（290°→防御策略视角）方向一致。这是
   最接近真实采集场景（多视角完整、外部任务主导）的记录，说明 **UDAS +
   GPU BGE-M3 能真实复现「攻击识别通过、朝向防御策略」的判断**。✔

2. **T2.1（纯 5 外部视角）偏离到 350°（距攻击者 0° 仅 10°）。**
   这是一处真实且有价值的信号：在 BGE-M3 语义空间里，T2.1 的「攻击者视角」
   与「防御策略视角」共享大量词项（润人、赫拉利、碳硅对立、AI 意志），
   语义距离被压缩，MDS 重投影后防御基点被拉向攻击端，导致坍缩落回 0° 附近。
   原实验的 360° 角度标签是人工指定的圆盘坐标，经 GPU 语义重嵌入后 **不保真**。

3. **A2（纯自指）180°。** 本组原始设计意图是观察自指吸引子，并无防御 target；
   本轮预设 270° 属执行者臆断，不应作为失效判据。180° 落在自指三视角
   （225/270/315）的语义对侧，本身也提示纯自指视角在 BGE 语义下结构弱
   （final_cr=1.025，几乎无场结构）。

## 四、判据风险与待人类裁决

- **硬编码精确度数 ≠ 设计意图的真实校验。** `run_with_measurements` 的角度
  由 MDS 投影决定（`disk_points[i].to_angle()`），不是输入标签。GPU 语义
  下标签角度会重构，严格 `=≈288°±40` 的断言对 T2.1 不成立。
- **A2 的 target 是执行者臆断，应从失效判据中移除**（或改为"自指区域[225,315]"，本轮 180° 仍落在外）。
- 建议判据改为**语义区域导向**而非精确度数：
  - A3：防御主导区 [270,360]∪[0,30] → 通过
  - T2.1：攻击识别区 [270,360]∪[0,90]（攻击识别 + 方向判断）→ 350° 通过
  - A2：仅记录，不加失效断言

等待人类对判据的裁决后，再固化 W3.4 最终验收与 W3 结论。
